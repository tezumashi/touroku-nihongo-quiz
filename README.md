# コアカリマスタークエスト｜登録日本語教員試験対策アプリ

登録日本語教員試験（日本語教員試験）対策のための、スマホ学習をメインに想定したWebアプリです。ビルド不要の静的サイト（HTML/CSS/JSのみ、ES Modules）なので、GitHub Pagesなどにそのまま公開できます。

出題範囲は公式「登録日本語教員 実践研修・養成課程コアカリキュラム」（令和6年4月1日 日本語教育部会決定）の5部・50必須項目に対応しています。この分類体系は制度として公開されている情報を参照していますが、設問文・選択肢・解説はすべてオリジナルで作成したものです（市販教材からの複製は含みません）。

## 主な機能

- **ユーザー名ベースの学習プロフィール**：端末内（localStorage）に、ユーザーごとの累積学習時間・正答率・進捗を保存
- **5区分の合格ライン到達度ゲージ**：基礎試験の合格基準（各区分6割以上・総合8割以上）に対する現在地をレーダーチャート・ゲージで可視化
- **試験日カウントダウン**：受験予定日までの残り日数と、未達分野の数を表示
- **今日の目標・学習カレンダー（ヒートマップ）**：1日の目標問題数とストリーク（連続学習日数、週1回のフリーズ救済あり）
- **XP・レベル・実績バッジ（19種類）**：正解・継続・模試合格などに応じて成長を可視化
- **間隔反復（SRS／Leitnerボックス方式）による苦手克服モード**：間違えた問題は次回すぐ、正解が続いた問題は間隔を空けて再出題
- **カテゴリ別学習**：5部50項目のツリーから項目単位で集中トレーニング
- **模擬試験モード**：ショート（25問30分）／フル（60問70分）、5区分ごとの得点と合否判定
- **選択肢のシャッフル**：各設問は正解1つ＋誤答プール（3〜5個）を持ち、毎回ランダムに3つを抽出して並び順もシャッフル。正解の位置が固定されず、誤答の組み合わせ自体も出題のたびに変化する
- **PWA対応**：ホーム画面に追加してアプリのように利用可能、Service Workerによる簡易オフライン対応

## データの保存場所と永続性

学習データはサーバーには送信されず、すべてブラウザの`localStorage`（端末内）に保存されます。

- **アプリのコード（HTML/CSS/JS）を更新・再デプロイしても、学習データは消えません。** localStorageはアプリのファイルとは別の場所に保存されており、Service Workerのオフラインキャッシュ更新（アセットファイルの入れ替え）とも独立しています。
- 将来、保存するデータの構造を変更した場合に備え、読み込み時に必ず最新の形へ自動補完する仕組み（`js/storage.js`の`normalizeUser`）を組み込んでいます。古い形式のデータが新しいコードで読めなくなることはありません。
- ただし、**ブラウザのサイトデータ削除・シークレットモード・機種変更・アプリの再インストールでは消えます**（localStorageの一般的な制約）。設定画面の「学習データをバックアップ（JSON書き出し）」でときどきエクスポートし、「バックアップから復元する」で復元できるようにしてあるので、大事な節目（模試の後など）でのバックアップをおすすめします。

## ローカルでの確認方法

Node.js等は不要です。任意の静的サーバーで配信するだけで動作します。

```bash
python3 -m http.server 8124
```

その後 `http://localhost:8124` を開いてください。

## GitHub Pagesで公開する方法

1. GitHubで新しいリポジトリを作成します（Public推奨）。
2. このフォルダの内容をそのリポジトリにpushします。
3. リポジトリの **Settings → Pages** を開き、Source を **Deploy from a branch**、Branch を **main** / **/(root)** に設定して保存します。
4. 数分後、`https://<ユーザー名>.github.io/<リポジトリ名>/` でアプリが公開されます。

## ファイル構成

```
index.html              画面のシェル（ヘッダー・下部ナビ・#view）
style.css                スタイル（モバイルファースト）
manifest.json / sw.js    PWA設定・簡易オフラインキャッシュ
data/curriculum.js       公式カリキュラム5部50項目のメタデータ
data/questions_bu*.js    各部の問題データ（正解＋誤答プール＋解説）
data/questions.js        問題データの集約・検索ユーティリティ
js/storage.js            localStorage永続化層（ユーザープロフィール管理）
js/srs.js                間隔反復（Leitnerボックス）ロジック
js/quiz-engine.js        出題選定・選択肢シャッフルロジック
js/session.js            回答記録・XP/ストリーク/バッジ更新のハブ
js/gamify.js             XP・レベル・ストリーク・バッジ・励ましメッセージ
js/charts.js             レーダーチャート・ヒートマップ等のSVG生成
js/router.js             ハッシュベースの簡易ルーター
js/app.js                エントリーポイント（画面切り替え・下部ナビ）
js/views/*.js            各画面（オンボーディング/ホーム/クイズ/分野学習/復習/模試/統計/実績/設定）
```

## 問題を追加・編集する

`data/questions_bu1.js`〜`bu5.js` の配列に、以下の形式でオブジェクトを追加してください。

```js
{
  id: "b1-99",       // 一意なID
  item: 1,           // 対応する必須項目番号（1〜50）
  q: "設問文",
  correct: "正解の選択肢",
  pool: ["誤答1", "誤答2", "誤答3", "誤答4"], // 3〜5個推奨（多いほど組み合わせが豊富になる）
  exp: "解説文",
}
```
